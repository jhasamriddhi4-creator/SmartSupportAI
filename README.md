# SmartSupport AI

An intelligent AI-powered Customer Support Assistant built using Prompt Engineering and Large Language Models.

## Features

- Multi-Prompt Architecture
- Intent Detection
- Prompt Routing
- Few-Shot Prompting
- Prompt Chaining
- Human Escalation
- Conversation Memory
- Evaluation Dashboard
- Streamlit Interface

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Prompt Engineering

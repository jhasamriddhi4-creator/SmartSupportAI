# 🤖 SmartSupport AI

An AI-powered Customer Support Assistant built using Prompt Engineering techniques and Google's Gemini API.

---

## 📌 Project Overview

SmartSupport AI is an intelligent chatbot that automatically classifies customer queries and routes them to specialized prompt templates.

It demonstrates:

- Prompt Engineering
- Prompt Chaining
- Few-shot Prompting
- Intent Classification
- Customer Support Automation
